# SummarEase — Hugging Face Text Summarizer

SummarEase is a lightweight Gradio application that turns long text into a concise summary using Hugging Face's text summarization models. The project is designed as a simple AI demo that can be deployed on Hugging Face Spaces and used to quickly test how summarization works in a browser-based interface.

## What this app does

- Accepts a block of text from the user
- Sends the text to a Hugging Face summarization pipeline
- Returns a shorter summary generated by the model
- Provides a clean and simple web interface powered by Gradio

## Why this project matters

This project is useful for:

- learning how Hugging Face Transformers work in a real app
- creating a quick AI demo without a complex backend
- demonstrating text summarization in a browser
- deploying a machine learning app to Hugging Face Spaces

## Tech stack

- Python
- Gradio for the UI
- Hugging Face Transformers for NLP models
- TensorFlow / tf-keras as part of the environment setup

## How it works

The app is built around a single file, `app.py`:

```python
from transformers import pipeline
import gradio as gr

model = pipeline("summarization")


def predict(prompt):
    summary = model(prompt)[0]["summary_text"]
    return summary

with gr.Blocks() as demo:
    gr.Markdown("## Text Summarization App")
    gr.Markdown("Enter a block of text below and click Submit to generate a summary.")

    with gr.Row():
        textbox = gr.Textbox(placeholder="Enter text to summarize", lines=6)

    submit_btn = gr.Button("Summarize")
    output = gr.Textbox(label="Summary", interactive=False)

    submit_btn.click(predict, inputs=textbox, outputs=output)

demo.launch()
```

This creates a simple Gradio interface where a user inputs text and receives a summarized version.

## Quick start

1. Clone the repository:

```bash
git clone https://github.com/Muhammadyousafrana/SummarEase-Hugging-Face-Text-Summarizer.git
cd SummarEase-Hugging-Face-Text-Summarizer
```

2. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

3. Install dependencies:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

4. Run the app:

```bash
python app.py
```

5. Open the local Gradio URL shown in the terminal (typically `http://127.0.0.1:7860`).

## Deployment on Hugging Face Spaces

This project is set up to be deployed on Hugging Face Spaces. The repository includes a workflow in `.github/workflows/main.yml` that pushes the app to a Hugging Face Space.

To deploy it:

1. Create a Hugging Face Space.
2. Add the Hugging Face token to your GitHub repository secrets.
3. Update the workflow if your Space name differs from the configured one.
4. Push to the `main` branch to trigger deployment.
